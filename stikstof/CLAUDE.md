# Stikstof

Visual explainer of the Dutch nitrogen crisis, in two languages:

- `index.html` — Dutch (the original)
- `en/index.html` — English translation

Both pages share the same CSS and script; only the text differs (plus the `toLocaleString` locale and the label strings in the script). When you change one page, make the same change to the other. The NL/EN switch (`nav.taal`) sits at the top right of both pages.
