Things that go wrong: 404

A request always gets an answer, even when the answer is bad news. The answer arrives as a status code.

A broken image

The tag below points at images/missing.png, a file that is not on the server. The request still happens; it just comes back 404 Not Found, shown in red in the Network tab. That is why you see a broken image icon instead of a picture.

A broken link

The same thing happens when you click a link to a page that does not exist. Try this link, then look at the status of the new row: 404 again, and the server sends back an error page instead of the page you wanted.

Codes worth remembering

CodeMeaning
200OK — here is the file
304Not Modified — your cached copy is still good
404Not Found — no such file on this server
403Forbidden — it exists, but you are not allowed it
500Internal Server Error — the server broke
