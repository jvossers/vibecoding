Three images = three extra requests

There is no bulk discount. Each picture is a separate file on the server, so each one needs its own request. Count the rows: you should get four.

Look at the Type column: two rows say png and one says svg+xml. The server tells the browser what kind of file it is sending using a response header called Content-Type.

An SVG is not a photo — it is text describing shapes. Open images/logo.svg directly and view its source: it is readable, just like the HTML.

This page: 4 requests. 1 HTML + 3 images.
