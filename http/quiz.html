Count the requests

Predict the answer first, then click the link and check the Network tab. Clear the list with the 🚫 button before each one so it is easy to count.

1. How many requests does this page make?

Show the answer

1. It is HTML only — no images, no external stylesheet.

2. How many does this page make?

Show the answer

4. The HTML, then one request for each of the three pictures.

3. Two of the pages here make exactly 2 requests, but for different reasons. Which are they?

Show the answer

One image (HTML + a picture) and An external stylesheet (HTML + a CSS file). A big image and Things that go wrong also make 2 — so really there are four.

4. This page shows one picture. Why does it still only make 2 requests?

Show the answer

The HTML plus one image. The <details> boxes and all the styling are built into the HTML file, so revealing an answer costs nothing: click one and watch — no new row appears, because nothing new is fetched.

5. You reload a page you have just visited, with the cache switched on. Does the browser send any requests?

Show the answer

Usually yes, but they are cheap. It may serve files straight from the cache (Size says disk cache), or ask the server and get 304 Not Modified back. See cached images.

This page: 2 requests. 1 HTML + 1 image.
