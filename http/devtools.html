How to read the Network panel

Each row in the Network tab is one HTTP request and its response. Load this page and you get exactly one row, because this page asks for nothing else.

The columns that matter

ColumnWhat it tells you
NameWhich file was asked for, e.g. devtools.html
StatusThe response code. 200 = here it is. 304 = you already have it. 404 = no such file.
Typedocument for a page, png or svg+xml for a picture, stylesheet for CSS.
SizeHow many bytes came back over the network.
TimeHow long the round trip took.

The order tells a story

The HTML always arrives first. The browser cannot know a page needs a picture until it has read the HTML and found the <img> tag. So it is always: ask for the page, read the page, then ask for whatever the page mentions.

Try this

Click a row to open it, then look at Headers. You will see the request headers your browser sent (including Host and User-Agent) and the response headers the server sent back (including Content-Type).
