HTTP requests: a click-along demo

Every time you click a link, your browser sends an HTTP request to a server, and the server sends back an HTTP response. Nothing here is hidden: this site is a handful of plain HTML files, and you can watch every single request happen.

Set up first (30 seconds)

  1. Press F12 (or Ctrl+Shift+I) to open Chrome DevTools.
  2. Click the Network tab.
  3. Tick Disable cache, so every request really goes to the server.
  4. Leave DevTools open, then click the links below and watch the list grow.

New to the Network tab? Start with How to read the Network panel.

Two things you might also spot

  • favicon.ico — the browser asking for the little icon shown on the browser tab. It asks on its own; you never wrote a link to it. If the server has no icon, this comes back 404.
  • Right-click any page and choose View page source. What you see is exactly what came back in the response — nothing more.
