Switches and routers:
what's the difference?

Both boxes pass data along, so they're easy to mix up. Here's the short version: a switch moves data inside one network, and a router moves data between networks. Send some messages below and watch each one at work.

The big idea

Switch Inside a LAN

  • Connects devices together within one local area network (LAN).
  • Reads the MAC address of the device the data is going to.
  • Keeps a table of which MAC address is plugged into which port.
  • Sends the data only to the device it's meant for, not to every device.

Router Between networks

  • Connects different networks together, such as a LAN to the internet (a WAN).
  • Reads the IP address the packet is going to.
  • Uses a routing table to decide where to forward the packet next.
  • Works out a route for packets to reach their destination network.

Think of posting a letter. The IP address is the address written on the envelope: it says where the letter is finally going, and it never changes on the way.

The MAC address is more like "hand this to the next person in the chain". A switch is the post room inside one building, handing letters to the right desk. A router is the sorting office that decides which town the letter goes to next.

Don't confuse these with a wireless access point (WAP). A WAP lets wireless devices join a LAN. It doesn't choose routes and it isn't a router, even though it's often in the same box.

    Exam-style questions

    Write your answer first, then open the mark scheme. These are in the style of OCR J277 Paper 1 questions.

    1. State the purpose of a switch in a LAN. [1]

    Any one of:

    • To connect devices together on a LAN.
    • To receive data and send it on to the correct device on the LAN.
    2. Describe the role of a router. [2]

    1 mark each, up to 2:

    • Connects different networks together / connects a LAN to a WAN or the internet.
    • Receives packets and reads the destination IP address.
    • Forwards packets towards their destination / chooses the route a packet takes.
    3. Give two differences between a router and a switch. [2]

    1 mark for each difference. Each must say what both devices do, or be clearly comparative:

    • A switch connects devices within one network; a router connects different networks.
    • A switch uses MAC addresses; a router uses IP addresses.
    • A switch sends frames to the correct device on the LAN; a router forwards packets to other networks / chooses routes.

    "A router connects to the internet" on its own only gets the mark if you also say what the switch does instead.

    4. A school has a computer room with 30 desktop computers and a printer. Explain why the room needs a switch. [2]
    • The switch connects all the computers and the printer to each other to form a LAN (1).
    • It sends data only to the device it's addressed to, using its MAC address (1)…
    • …which reduces unnecessary traffic, so the network stays fast (1).
    5. A family's broadband "router" lets their laptops and games console go online. Identify two separate devices inside the box and state what each does. [4]

    1 mark for naming the device, 1 for its job, for two devices:

    • Router: sends packets between the home LAN and the internet.
    • Switch: connects the wired devices together on the home LAN.
    • Wireless access point: lets wireless devices connect to the LAN.
    • Modem: converts the signal from the broadband line into data the router can use.

    Exam tip: when a question asks for a difference, write one sentence that covers both devices, joined with "whereas". For example: "A switch uses MAC addresses to send data within a LAN, whereas a router uses IP addresses to send data between networks."

    Key words

    LAN
    Local area network. Covers a small area such as one building, and the hardware is usually owned by the organisation using it.
    WAN
    Wide area network. Covers a large geographical area and often uses lines owned by telecoms companies. The internet is the biggest WAN.
    MAC address
    A unique, permanent address given to a network interface card (NIC) when it's made. Used by switches to deliver data within a LAN.
    IP address
    An address given to a device on a network, which can change. Used by routers to send packets between networks.
    Packet
    A small chunk of data with a header holding the source and destination IP addresses.
    Frame
    What a packet travels inside on each link, with the source and destination MAC addresses.
    NIC
    Network interface card. The hardware that lets a device connect to a network; it has the MAC address.
